Account ID Searcher is a small utility mod for Geometry Dash that expands the default profile search.

## Features

- Search player profiles by **Account ID**
- Still supports **User ID** search
- Numeric input detection with search type selection
- Instant profile opening when searching by User ID
- Safe ID validation to prevent crashes with large numbers

## Usage

Enter numbers only in the profile search field.  
A dialog will appear allowing you to choose whether to search by **User ID** or **Account ID**.

If an account with the specified Account ID does not exist, a dash will be shown in the results.
