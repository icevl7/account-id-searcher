# Account ID Searcher

This mod expands the default profile search in Geometry Dash. It allows you to search for players not only by User ID, but also by Account ID.

To use this feature, simply enter numbers in the search field. You will then be prompted to choose the search type: User ID or Account ID.

You can optionally enable the "Always search by Account ID" setting to skip the selection popup and instantly open profiles when numeric input is used.

In the vanilla game, searching is only available by User ID. If an account with the specified Account ID does not exist, a dash will be shown in the results.
